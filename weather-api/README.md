# Weather API Wrapper

This is a lightweight wrapper for the Open-Meteo weather API.

## Setup
1. Ensure Node.js is installed.
2. Run `npm install` to install dependencies.
3. Start the server with `npm start`.

## API Endpoints
- GET /weather?lat={latitude}&lon={longitude}: Fetches weather data for specified coordinates.

## Running Tests
- Run `npm test` to execute the integration tests.
